# Mirobody 用户使用手册

## 一、产品概述

Mirobody 是你的健康数字分身。它把体检报告、穿戴设备数据和基因文件汇入同一份记录，用随包发布的 LOINC/UCUM 标准词表离线统一指标名称与单位，再由 AI agent 基于你的真实记录（而非模型记忆）回答可追溯的健康问题。

开源版把记录留在你自己的机器上。不做诊断、不开处方，回答不构成医疗建议。

## 二、登录与首次设置

### 登录
- 地址：http://127.0.0.1:18060/login
- 三种方式：邮箱+密码登录、注册新账号、邮箱验证码登录
- 演示账号：`you@mirobody.ai`，验证码 `111111`（点击「一键填入」自动填入）
- 另一演示账号：`mom@mirobody.ai`（只读共享给你，验证码同为 `111111`）
- 支持语言切换：English / 简体中文 / 繁體中文 / 日本語

### 首次设置（模型选择）
首次访问会跳转到 `/setup` 页面，选择由谁来处理健康数据：

| 选项 | 说明 | 需要 |
|---|---|---|
| 使用模型服务（上手最快） | 一个 API key 接入 OpenRouter/OpenAI/Gemini/DeepSeek 等，几秒出答案 | 一个 API key |
| 100% 在本机运行（最私密） | llama.cpp 本地运行两个开源模型，无需 key/账号 | 16G 内存，CPU 首答几分钟 |

支持的模型服务商：OpenRouter、阿里通义千问、Google Gemini、OpenAI、DeepSeek、Anthropic。填入 key 后点击「检测并使用」，key 加密存储于本部署数据库，仅发给对应服务商。

如暂不配置，点击「稍后再说」可先浏览已有数据（标准化引擎和数据查看不需要模型）。

## 四、核心功能与操作步骤

### ① 收集数据（数据页）
路径：侧边栏 → 数据

**上传文件：** 将体检报告拖到「文件」标签页。支持 PDF、JPG 手机照片、CSV、XLSX 等 23 种格式。文件原样保存，每条读数都可追溯到来源文件。

示例文件（仓库 `demo/upload/`）：
| 文件 | 格式 | 说明 |
|---|---|---|
| you_annual_checkup_2026-05.pdf | PDF | 体检套餐 |
| mom_physical_2026-06.jpg | JPG | 打印单手机照片 |
| you_lipid_panel_2026-08.csv | CSV | 化验所导出 |
| mom_clinic_visit_2026-07.xlsx | XLSX | 诊所录入表格 |

**写健康日记：** 在「记录」标签页的输入框写一句话，例如：
> 昨晚开始头疼，血压150/95，没发烧，每天早晚吃二甲双胍500mg

模型拆句分类，编码来自词表：头痛 → ICPC-3 NS01，血压 → LOINC 8480-6/8462-4，二甲双胍 → 用药清单。「没发烧」不会被记成发烧。

**导入 Apple Health：** 命令行执行 `mirobody import apple ~/Downloads/export.zip`

**连接设备：** 「连接数据源」标签页可连接 Garmin、Oura、Whoop 等穿戴设备。

**基因数据：** 「基因数据」标签页上传 23andMe、AncestryDNA、WeGene 导出或 VCF 文件，按 rsID、基因或区间查询。

### ② 查看指标（指标页）
路径：侧边栏 → 指标

三个标签：
- **指标：** 汇总表格，显示每项指标的名称、最新值、记录数、最近记录日期、LOINC 编码
- **明细：** 逐条读数详情
- **用药：** 用药清单

搜索框可按名称或缩写搜索指标。点击某行可查看趋势图和全部历史读数。

不同文件中同一指标的不同写法（如 `Total Cholesterol-TC` 与 `Cholesterol, Total`）会自动归并为同一条序列（都映射到 LOINC 14647-2），跨文件可比较。

### ③ 智能体问答（询问页）
路径：侧边栏 → 询问

- 点击「新对话」开始
- 在输入框用日常语言提问，例如：**「我的胆固醇有什么变化？」**
- agent 实时显示每一步（正在查询健康数据、正在阅读文件）
- 回答中每个数字下方有虚线，点击可查看该读数的值、日期、参考范围和来源文件
- 切换到共享记录（如 Mom）后，同一问题的答案来自另一个人的数据
- 「帮他问」按钮可快速切换查询的档案

### ④ 关爱圈与家人共享
路径：侧边栏 → 关爱圈

- **添加成员：** 邀请家人共享记录，或替不登录的长辈代管一份档案
- **权限控制：** 每个成员可设为「可以查看和管理」「只能查看」「不共享」
- **四条承诺：** 必须本人接受才算加入；健康数据默认不开；开关在你自己的行上；每个成员各管各的
- 代管的家人可发送邀请链接让其接管，接管后由本人重新决定你的权限

### ⑤ 个人档案
路径：侧边栏 → 档案

填写姓名、出生日期等基本信息。年龄由出生日期推算，这些信息在回答健康数据问题时被用到。

## 六、常见问题

**Q: 登录后看不到数据？**
A: 演示数据在 `SEED_DEMO_DATA=true` 时自动注入。确认 deploy.sh 已正常启动所有容器（`docker compose ps` 全部 healthy）。

**Q: 问问题时报错「no LLM model」？**
A: 需在首次设置页（`/setup`）配置一个模型 API key，或在 `.env` 中写入 `OPENROUTER_API_KEY=sk-or-...` 后执行 `docker compose up -d`。

**Q: 上传文件后指标没出来？**
A: 文档解析需要模型。配置模型 key 后重新上传，或检查 `docker compose logs mirobody` 是否有解析错误。

**Q: 不同医院的报告能比较吗？**
A: 可以。Mirobody 用 LOINC 编码统一不同写法的同一指标（如中英文的血红蛋白都映射到 718-7），单位用 UCUM 标准化，跨文件自动归并为可比较的趋势线。

**Q: 数据安全吗？**
A: 开源版数据只存在你自己的机器上（PostgreSQL 加密存储）。模型 key 加密保存，仅发给对应服务商。绑定 127.0.0.1 仅本机可访问。

**Q: 不配模型能用什么？**
A: 标准化引擎（名称/单位解析）、数据浏览、基因数据查询均可离线使用，不需要模型。仅文档解析和 AI 问答需要模型。

**Q: 如何接入 Claude Code/Cursor？**
A: 应用内「设置 → MCP 链接」生成链接（默认 10 天有效），或命令行 `uvx --python 3.12 mirobody mcp` 通过 stdio 使用离线词表工具。

**Q: 如何停止/重启服务？**
A: `cd repos/mirobody && docker compose down` 停止；`./deploy.sh` 重启；`docker compose logs -f` 查看日志。
